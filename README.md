# Ibogaine Guide — Sanctuary edition (site 3)

Third skin of the same site: immersive retreat aesthetic inspired by ambio.life — deep pine, warm cream, dusty-rose pill CTAs, Plus Jakarta Sans + Lora, full-bleed photography, and a GSAP motion layer (Lenis smooth scroll, staggered reveals, image parallax, animated counters). All animation is decorative: content is fully readable with JS disabled, and `prefers-reduced-motion` skips motion entirely.

Same content and structure as `ibogaine-review/` (33 pages), generated by `_generator/build_site.py` — run `python3 _generator/build_site.py` after content edits.

## Forms

All submissions go to one Google Sheet via an Apps Script web app. Set it up once
with `_generator/apps-script/SETUP.md`, then put the deployment URL and token at the
top of `js/main.js`. Until those are set, every form shows a "not connected yet"
notice rather than failing silently.

Four destinations: `screening-quiz` (is-ibogaine-right-for-me.html), `provider-match`
(find-a-provider.html, including ECG/blood work uploads to Drive), `consultation`,
and `resource-gate`. Adding a question to a survey adds a column on the next
submission — no script change needed.
